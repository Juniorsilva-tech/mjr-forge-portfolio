## Sobre o projeto

Este portfólio foi criado para ser mais do que uma página pessoal. A proposta é apresentar uma identidade visual forte, cinematográfica e moderna, conectada ao meu principal diferencial: construir interfaces com mentalidade de produto, estética premium e apoio de automações/IA no processo de entrega.

O site comunica três frentes principais:

- busca por **estágio/primeira oportunidade como Front-end React**;
- disponibilidade para **freelas de landing pages, dashboards e interfaces modernas**;
- desenvolvimento do **Jarvis Coding OS**, meu workflow próprio com IA para geração, QA e refinamento de projetos web.

---

## Destaques

- Hero section cinematográfica com identidade visual própria.
- Background animado em Canvas inspirado em buraco negro, disco de acreção e estética sci-fi premium.
- Cursor customizado com comportamento suave e responsivo.
- Interface construída com React, Tailwind CSS e Framer Motion.
- Seções focadas em prova real, sinais de contratação, Jarvis e projetos.
- Mockups conceituais para representar projetos enquanto prints reais ainda estão sendo produzidos.
- Layout responsivo para desktop e mobile.
- Deploy em produção via Vercel.
