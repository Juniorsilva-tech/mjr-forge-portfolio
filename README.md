# MJR Forge Portfolio

Portfólio premium de Maurício Júnior — Front-end React com UI premium, automação e IA aplicada à entrega.

- React
- Vite
- Tailwind CSS
- Framer Motion

## Rodar localmente

```bash

npm run dev
```
