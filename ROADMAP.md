# MJR Forge Portfolio — Roadmap

Roadmap público de evolução do portfólio MJR Forge.

O objetivo deste roadmap é organizar melhorias futuras para tornar o projeto mais forte como vitrine profissional para vagas, freelas e demonstração de UI/UX.

---

## Fase 1 — Base Atual

Status: em andamento

- Portfólio React publicado na Vercel
- Identidade visual própria
- Interface dark premium
- Animações com Framer Motion
- Background visual em Canvas
- Seções de projetos, contato e posicionamento profissional

---

## Fase 2 — Performance e Responsividade

- Criar Performance Mode para reduzir efeitos visuais em dispositivos mais fracos
- Melhorar fluidez em mobile
- Reduzir custo de renderização do Canvas
- Melhorar carregamento inicial
- Medir performance com Lighthouse
- Ajustar animações para evitar excesso visual

---

## Fase 3 — Prova Real de Projetos

- Adicionar screenshots reais do RetailFlow
- Adicionar screenshots reais do Jarvis Lite ou workflow de QA
- Criar estudos de caso com problema, solução e resultado
- Adicionar links diretos para deploys e repositórios
- Adicionar seção de projetos com mais contexto técnico

---

## Fase 4 — SEO e Apresentação Profissional

- Melhorar metadata
- Melhorar Open Graph
- Criar imagem de preview social
- Melhorar copywriting
- Melhorar acessibilidade
- Adicionar seção de stack técnica organizada

---

## Fase 5 — Evolução Comercial

- Criar página de serviços freelance
- Adicionar exemplos de landing pages
- Adicionar proposta de valor para pequenos negócios
- Criar call-to-action mais direto para clientes
- Criar versão em inglês para oportunidades internacionais

---

## Visão

O MJR Forge deve evoluir de um portfólio visual para uma vitrine profissional completa, mostrando capacidade técnica, senso visual, mentalidade de produto e entrega prática com React.
